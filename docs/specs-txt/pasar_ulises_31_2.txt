
ESPECIFICACIÓN TÉCNICA: FILTROS DE ENTRADA Y PRECISIÓN INSTITUCIONAL
Filtro de Contexto de Mercado (SPY / Merval) + Filtro de Vigencia (No Perseguir Precios)
| ANEXO PARA EL DESARROLLADOR (ULISES): Este anexo técnico contiene los 2 filtros críticos de validación previa a la compra. El bot debe procesar estas condiciones de forma obligatoria ANTES de emitir cualquier orden. Si alguno de los dos filtros no se cumple, la compra se aborta de forma preventiva.

1. Cuadro de Especificación de los Dos Filtros de Calidad
| Filtro
| Regla Matemática / Umbral
| Objetivo / Comportamiento
| Filtro 1: Contexto de Mercado (Market Regime)
| Índice > SMA_200 (Gráfico diario) Y Retorno_Diario_Índice >= -1.0%
| Evita abrir posiciones compradoras en días de caída generalizada o pánico bursátil. Si el índice de referencia (SPY para CEDEARs o IMV para acciones locales) cae con fuerza, se bloquean todas las compras.
| Filtro 2: Vigencia de Señal (Anti-Chasing)
| Precio_Actual <= Nivel_Ruptura * 1.010 (Tolerancia máxima: +1.0%)
| Impide 'perseguir' el precio al alza. Si la señal técnica se disparó pero el papel ya trepó más de 1.0% respecto al punto de ruptura, el bot descarta la entrada para no comprar en el techo del impulso.

2. Explicación Operativa de los Filtros
• Por qué el Filtro de Contexto evita pérdidas: Estadísticamente, cuando el mercado de referencia (S&P 500 o Merval) registra una rueda de liquidación masiva (caídas > 1%), entre el 75% y el 85% de las acciones individuales son arrastradas a la baja sin importar su calidad técnica. Exigir que el benchmark esté cotizando por encima de su media y sin caídas abruptas en la jornada actual filtra más de la mitad de las operaciones falsas (falsos breakouts).
• Por qué el Filtro de Vigencia protege el Ratio Riesgo/Beneficio: Si el Stop Loss inicial está fijado en -3.0% desde el punto de ruptura, y el bot entra cuando la acción ya subió un 2.5%, el riesgo real asumido aumenta a más del 5.0% hasta el soporte, arruinando la matemática. Con una tolerancia máxima estricta del 1.0%, garantizamos que la distancia al Stop Loss se mantenga siempre dentro del rango óptimo planeado.

3. Módulo en Python para Integración en el Bot (EntryFilter)
| # ==============================================================================# MÓDULO DE VALIDACIÓN DE ENTRADAS: CONTEXTO DE MERCADO Y VIGENCIA DE SEÑAL# Para: Ulises (Bot de Trading)# ==============================================================================class EntryValidator:    def __init__(self, max_chase_pct: float = 0.010, market_min_change: float = -0.010):        """        :param max_chase_pct: Tolerancia máxima de persecución (1.0% por defecto)        :param market_min_change: Caída intradiaria máxima tolerada en el índice (-1.0%)        """        self.max_chase_pct = max_chase_pct        self.market_min_change = market_min_change    def is_market_healthy(self, market_index_price: float, market_index_sma200: float, market_daily_change_pct: float) -> tuple[bool, str]:        """        FILTRO 1: Evalúa si el índice general (SPY o Merval) permite operar.        """        # 1. Filtro de tendencia macro del mercado        if market_index_price < market_index_sma200:            return False, "Mercado bajo SMA200 (Tendencia bajista general activa)"        # 2. Filtro de caída intradiaria / día de pánico        if market_daily_change_pct < self.market_min_change:            return False, f"Día de venta masiva en índice ({market_daily_change_pct*100:.2f}% < {self.market_min_change*100:.1f}%)"        return True, "Mercado saludable y apto para compras"    def is_signal_valid(self, current_price: float, breakout_level: float) -> tuple[bool, str]:        """        FILTRO 2: Evalúa si el activo no se escapó respecto al nivel de entrada original.        """        if current_price < breakout_level:            return False, "Precio actual aún no superó el nivel de ruptura"        chase_distance = (current_price / breakout_level) - 1.0        if chase_distance > self.max_chase_pct:            return False, f"Señal vencida: Precio extendido un {chase_distance*100:.2f}% (Máximo permitido: {self.max_chase_pct*100:.1f}%)"        return True, f"Entrada válida: En rango óptimo (+{chase_distance*100:.2f}% de la ruptura)"    def can_open_position(self, current_price: float, breakout_level: float,                           market_price: float, market_sma200: float, market_change_pct: float) -> tuple[bool, str]:        """        Compuerta lógica final: Valida ambos filtros antes de autorizar la orden de compra.        """        market_ok, mkt_msg = self.is_market_healthy(market_price, market_sma200, market_change_pct)        if not market_ok:            return False, f"COMPRA RECHAZADA: {mkt_msg}"        signal_ok, sig_msg = self.is_signal_valid(current_price, breakout_level)        if not signal_ok:            return False, f"COMPRA RECHAZADA: {sig_msg}"        return True, "COMPRA APROBADA: Ambos filtros verificados con éxito"

5. Checklist de Integración para Ulises
✔ Fuente de Datos del Benchmark: Para operar CEDEARs utilizar SPY (S&P 500) o QQQ (Nasdaq) como referencia de mercado; para acciones argentinas utilizar el índice Merval (IMV).
✔ Orden de Ejecución de Filtros: Ejecutar siempre el Filtro 1 (Mercado) en primer lugar para descartar toda la lista de seguimiento en bloque si el día es adverso, ahorrando peticiones a la API del broker.
✔ Cálculo del Breakout: El nivel de entrada 'breakout_level' debe congelarse en el instante exacto en que se valida la señal técnica; sobre ese número fijo se evalúa el umbral del 1.0% de tolerancia.
✔ Compatibilidad con Salidas: Una vez aprobada la compra por este módulo, el control pasa directamente al módulo PositionManager (SL -3.0%, TP1 50% en +4.5%, Trailing 1.2% y Cierre 16:50 hs).
