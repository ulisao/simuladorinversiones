Take Profit Parcial (TP1 50%) + Trailing Stop (1.2%) con Piso + Cierre Preventivo Intradiario (16:50 hs)
| ACTUALIZACIÓN PARA EL DESARROLLADOR (ULISES): Documento técnico completo para Ulises. Se incluye la nueva regla obligatoria de CIERRE INTRADIARIO PREVENTIVO a las 16:50 hs (Opción A: cerrar todo en verde antes de que finalice la rueda de BYMA para evitar el riesgo de Gap bajista nocturno). Contiene lógica paso a paso, simulación y códigos listos en Python y Pine Script v5.

1. Cuadro Resumen de Parámetros y Reglas de Salida
| Parámetro
| Valor Exacto
| Descripción / Acción Operativa
| Stop Loss Inicial (SL0)
| -3.00%
| Protección fija inicial sobre el 100% de la posición desde el precio de entrada.
| Take Profit 1 (TP1)
| +4.50% a +5.00%
| Venta a mercado del 50% de las acciones. Cancela inmediatamente el SL0 de -3.0%.
| Piso Mínimo Garantizado
| +3.50%
| Piso mínimo infranqueable para el 50% restante una vez disparado el TP1.
| Distancia Trailing Stop
| 1.20%
| Retroceso máximo tolerado desde el pico más alto registrado (High-Water Mark).
| Take Profit 2 (TP2 / Techo)
| +7.00% a +8.00%
| Cierre automático del 50% restante si la tendencia alcanza la meta superior sin recortar 1.2%.
| Cierre por Fin de Rueda (Opción A)
| 16:50 hs (ART)
| Si hay posición restante post-TP1, se liquida a mercado a las 16:50 hs. Cero riesgo overnight.

2. Ciclo de Vida, Lógica Operativa y Regla de las 16:50 hs
• Fase 1: Entrada y SL Inicial (-3.0%): Compra 100% a Precio_Entrada. SL fijo inicial = Precio_Entrada * 0.97. Si cae a ese nivel, sale el 100% y corta pérdida.
• Fase 2: Gatillo TP1 (50% Out en +4.5%): Al tocar Precio_Entrada * 1.045, se vende a mercado el 50% de las acciones. Se cancela inmediatamente el SL0 de -3.0%.
• Fase 3: Trailing Stop (1.2%) con Piso (+3.5%): Para el 50% restante se activa el stop dinámico: Trailing_Stop = max(Precio_Entrada * 1.035, max_price * (1 - 0.012)). El stop es monótono creciente (solo sube). Si el precio retrocede 1.2% desde su pico, se liquida el restante.
• Fase 4: Regla de Cierre Preventivo de Mercado (16:50 hs ART - Opción A): A las 16:50 hs (10 minutos antes del cierre formal de BYMA a las 17:00 hs), el bot verifica si existe posición abierta con TP1 cobrado. De ser así, envía una orden MARKET SELL automática y cierra la posición completa. MOTIVO: Eliminar al 100% el riesgo de Gap Bajista Overnight (aperturas con huecos negativos a las 11:00 AM del día siguiente ocasionadas por caídas nocturnas en Wall Street o noticias locales). Se prioriza asegurar el profit real en caja.

3. Implementación en Python con Control Horario (16:50 hs)
| # ==============================================================================# GESTOR DE SALIDAS DINÁMICAS + CIERRE PREVENTIVO 16:50 HS (BYMA / ARG)# Para: Ulises (Bot de Trading)# ==============================================================================from datetime import datetime, timeimport pytzclass PositionManager:    def __init__(self, symbol: str, entry_price: float, total_qty: int):        self.symbol = symbol        self.entry_price = entry_price        self.total_qty = total_qty        self.remaining_qty = total_qty                # Parámetros Operativos        self.sl_initial_pct = 0.030      # Stop Loss inicial: -3.0%        self.tp1_pct = 0.045             # Take Profit 1: +4.5% (vende 50%)        self.trailing_pullback = 0.012   # Retroceso Trailing: 1.2%        self.min_guaranteed_pct = 0.035  # Piso mínimo garantizado: +3.5%        self.tp2_pct = 0.080             # Take Profit 2 final: +8.0%                # Horario de Cierre Preventivo (Argentina: UTC-3)        self.tz = pytz.timezone("America/Argentina/Buenos_Aires")        self.market_close_cutoff = time(16, 50, 0)                # Estado Interno        self.is_tp1_hit = False        self.is_closed = False        self.max_price_since_tp1 = 0.0        self.current_stop_price = entry_price * (1.0 - self.sl_initial_pct)    def on_tick(self, current_price: float, timestamp: datetime = None) -> dict:        """        Evalúa condiciones de salida en cada tick / vela.        """        if self.is_closed:            return None        # Obtener hora actual en zona horaria de Argentina        if timestamp is None:            now_art = datetime.now(self.tz).time()        else:            now_art = timestamp.astimezone(self.tz).time()        # -------------------------------------------------------------        # REGLA PRIORITARIA: CIERRE INTRADIARIO PREVENTIVO (16:50 hs)        # Si ya cobró TP1 y el mercado está por cerrar, liquida todo.        # -------------------------------------------------------------        if self.is_tp1_hit and now_art >= self.market_close_cutoff:            self.is_closed = True            qty_to_sell = self.remaining_qty            self.remaining_qty = 0            return {                "action": "SELL",                "reason": "END_OF_DAY_CUTOFF_1650",                "qty": qty_to_sell,                "price": current_price,                "profit_pct": ((current_price / self.entry_price) - 1) * 100,                "note": "Cierre preventivo para evitar Gap bajista nocturno"            }        # -------------------------------------------------------------        # CASO 1: Posición Inicial (Aún no tocó TP1)        # -------------------------------------------------------------        if not self.is_tp1_hit:            # 1.1 Stop Loss Inicial (-3.0%)            if current_price <= self.current_stop_price:                self.is_closed = True                qty_to_sell = self.remaining_qty                self.remaining_qty = 0                return {                    "action": "SELL",                    "reason": "INITIAL_STOP_LOSS_HIT",                    "qty": qty_to_sell,                    "price": current_price,                    "profit_pct": ((current_price / self.entry_price) - 1) * 100                }            # 1.2 Take Profit 1 (+4.5%)            if current_price >= self.entry_price * (1.0 + self.tp1_pct):                self.is_tp1_hit = True                qty_tp1 = self.total_qty // 2  # Vende el 50%                self.remaining_qty -= qty_tp1                                # Activa Trailing Stop con piso mínimo garantizado en +3.5%                self.max_price_since_tp1 = current_price                initial_trailing = current_price * (1.0 - self.trailing_pullback)                guaranteed_floor = self.entry_price * (1.0 + self.min_guaranteed_pct)                self.current_stop_price = max(guaranteed_floor, initial_trailing)                                return {                    "action": "SELL",                    "reason": "TP1_PARTIAL_50PCT",                    "qty": qty_tp1,                    "price": current_price,                    "profit_pct": ((current_price / self.entry_price) - 1) * 100,                    "new_stop_price": self.current_stop_price                }        # -------------------------------------------------------------        # CASO 2: Post-TP1 (Gestión Dinámica Trailing 1.2%)        # -------------------------------------------------------------        else:            # 2.1 Actualizar máximo relativo si hace nuevo pico            if current_price > self.max_price_since_tp1:                self.max_price_since_tp1 = current_price                calculated_stop = current_price * (1.0 - self.trailing_pullback)                if calculated_stop > self.current_stop_price:                    self.current_stop_price = calculated_stop            # 2.2 TP2 Techo (+8.0%)            if current_price >= self.entry_price * (1.0 + self.tp2_pct):                self.is_closed = True                qty_to_sell = self.remaining_qty                self.remaining_qty = 0                return {                    "action": "SELL",                    "reason": "TP2_CEILING_HIT",                    "qty": qty_to_sell,                    "price": current_price,                    "profit_pct": ((current_price / self.entry_price) - 1) * 100                }            # 2.3 Trailing Stop Hit (Retroceso de 1.2%)            if current_price <= self.current_stop_price:                self.is_closed = True                qty_to_sell = self.remaining_qty                self.remaining_qty = 0                return {                    "action": "SELL",                    "reason": "TRAILING_STOP_1.2PCT_HIT",                    "qty": qty_to_sell,                    "price": current_price,                    "profit_pct": ((current_price / self.entry_price) - 1) * 100                }        return None

5. Checklist Técnico de Producción para Ulises
✔ Sincronización NTP del Servidor: Asegurar que el servidor del bot tenga sincronizada la hora con servidor NTP oficial de Argentina (UTC-3) para disparar la orden a las 16:50:00 exactas.
✔ Cancelación de Orden Huérfana: Al ejecutarse el TP1, cancelar de inmediato el Stop Loss original de -3.0% en la API antes de registrar el Trailing.
✔ Persistencia de Estado: Guardar en base de datos local (SQLite o JSON) las variables 'is_tp1_hit', 'max_price_since_tp1' y 'current_stop_price' para no perder el seguimiento si se reinicia el script durante la rueda.
✔ Tipo de Orden para las 16:50 hs: La orden de cierre por horario debe enviarse estrictamente como MARKET ORDER (orden a mercado) para garantizar la ejecución inmediata antes del toque de campana de las 17:00 hs.
